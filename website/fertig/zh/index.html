简介

OrangeDeck 是一个比特币内存池可视化工具。它按内存池的真实变化来绘制：每笔等待确认的交易都是一个方块。它们堆积、被打包、被替换，你直接看到这一过程，而不是去读一个数字。

围绕它还有五个视图：适合挂在墙上的平板的区块高度时钟，来自你自己的 Bitaxe 和全网的挖矿数据，区块浏览器，带蜡烛图、累计成交量差和强平数据的市场页面，以及只读的地址监视。

六个视图

  • 01动态以动态拼图呈现的内存池，旁边是最新的区块。颜色可按存在时间、手续费或交易类型区分。
  • 02时钟用大字显示区块高度、手续费、价格、算力和减半倒计时，界面上没有任何按钮。适合挂在墙上的平板。
  • 03挖矿一个 Bitaxe 监控：显示你自己矿机的算力、最佳份额与全网难度的对比、温度和功率。旁边是全网的算力、难度和下次难度调整。
  • 04浏览器按区块高度、哈希、txid 或地址搜索。浏览区块及其内容，查看哪笔交易替换了哪笔。
  • 05市场以蜡烛图或折线显示价格，并显示成交量、累计成交量差和强平，数据汇总自多家交易所。
  • 06钱包只读查看你自己的地址或 xpub。你的交易在堆里等待时会被高亮显示。需要在一台 Linux 电脑上运行 OrangeDeck 服务，手机和 Windows 通过家庭网络访问它。

适用场景

  • Bitaxe 监控你自己矿机的算力、最佳份额和温度，与全网数据并排显示。
  • 挂墙显示用大号数字显示区块高度、手续费和价格，适合旧平板。
  • DankMaterialShell适用于 DMS 的状态栏胶囊、控制中心磁贴和桌面小部件。

运行平台

  • 任何 Linux 桌面普通窗口。支持 Wayland，也可退回到 X11。
  • 作为小部件或状态栏在 niri、sway、Hyprland、river、labwc 上使用 layer-shell。
  • 在 DankMaterialShell 中已收录在 DMS 插件目录中。可作为仪表盘标签页、状态栏胶囊、控制中心磁贴或桌面小部件使用。
  • Windows一个 ZIP 包，解压即可运行。视图相同；钱包数据来自同一网络中一台 Linux 电脑上的服务。
  • macOS可以编译，但尚未测试。目前还没有安装包。
  • Android手机或平板均可。每个视图都有自己的主屏幕快捷方式。

数据来源

  • 区块、内存池、手续费、算力mempool.space 的公开 WebSocket，或你自己的 mempool 实例，只需改一项设置。
  • 价格和成交Binance、Bybit 和 OKX 的公开数据流。
  • 强平Bybit 和 OKX。热力图是根据 Binance 未平仓合约建立的模型，屏幕上也写明了这一点。
  • 你自己的矿机设备的本地 API，即 AxeOS 或 cgminer。请求不会离开你的家庭网络。
  • 监视的地址向同一个 mempool 实例查询余额。不涉及密钥，除此之外没有任何数据离开设备。

为什么选择 OrangeDeck

  • 01它只是一个查看器它不知道任何私钥，不能签名，也不包含任何能签名的库。只读就是只读。
  • 02没有我们自己的服务器它只连接 mempool.space 或你自己的节点。没有统计，没有崩溃报告，也没有账户。
  • 03实测，而非猜测如果某个数字来自模型而不是实测，比如强平热力图，屏幕上会写明，并列出所用的假设。
  • 04一套代码，五种环境窗口、小部件、面板和手机都由同一套 QML 绘制。在一处修好的问题，在所有地方都修好了。
  • 05代码可以自己读MIT 许可证，没有混淆，每次改动的理由都写在提交信息里。

常见问题

需要我的密钥吗？

不需要。它什么都不能签名。要监视的地址以地址或 xpub 的形式输入，除了查询余额之外，不会离开你的设备。

数据从哪里来？

默认来自 mempool.space，也可以来自你自己的 mempool 实例，只需改一项设置。行情数据来自交易所的公开数据流。

它会向外发送数据吗？

不会。没有我们自己的服务器，没有统计分析，也没有崩溃报告。

要花钱吗？

不要。它采用 MIT 许可证，没有付费版本。

支持哪些语言？

十三种：英语、德语、西班牙语、法语、意大利语、葡萄牙语（葡萄牙和巴西）、荷兰语、俄语、日语、中文、波兰语和捷克语。启动时使用系统语言，数字和日期格式跟随你在设置中选择的语言。

强平热力图是真实数据吗？

不是，屏幕上也写明了。没有人会公开别人的仓位；它是一个列明了假设的模型。

可以在墙上的平板上运行吗？

时钟视图就是为此设计的：大号数字，没有按钮。Android 版带有直接打开时钟的快捷方式。
