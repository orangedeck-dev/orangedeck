メンプールの横に Bitaxe モニター

OrangeDeck のマイニング画面は、マイナーをローカル API で読み取り、ハッシュレート、最高シェア、温度、電力、ファンの回転数を表示します。Bitaxe や NerdAxe などの AxeOS デバイスのほか、Antminer、Avalon、Whatsminer など cgminer API を話す機器も認識します。

設定はアドレスだけで、複数のマイナーは縦棒で区切って同じ欄に入力します。問い合わせはホームネットワーク内のデバイスにだけ送られます。クラウドのアカウントもプールへのログインもありません。

最高シェアは現在のネットワーク難易度と比べて表示され、あなたのハッシュレートでブロックを見つける確率を、1日あたりと平均間隔で計算します。Bitaxe 1台ならその間隔はとても長くなりますが、OrangeDeck はその数字をそのまま表示します。

デバイスの横にはネットワークの数値が並びます。30日前から2009年までのハッシュレートと難易度、次の難易度調整、平均ブロック時間、直近のブロックを掘ったプールです。

この画面はウィジェットとしても動きます。Linux ではデスクトップ上の layer-shell サーフェス、Windows では枠のないウィンドウ、Android ではホーム画面のウィジェットになります。

よくある質問

OrangeDeck はどのマイナーに対応していますか？

Bitaxe や NerdAxe などの AxeOS デバイスと、Antminer、Avalon、Whatsminer など cgminer API を備えたマイナーです。

マイナーのデータはネットワークの外に出ますか？

いいえ。OrangeDeck はデバイスのローカルアドレスに直接問い合わせます。サーバーは経由しません。

複数のマイナーを監視できますか？

できます。設定でアドレスを縦棒で区切って入力してください。例：http://192.168.1.42|http://192.168.1.43
