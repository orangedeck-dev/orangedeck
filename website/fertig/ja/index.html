概要

OrangeDeck はビットコインのメンプールを可視化するアプリです。メンプールを実際の動きどおりに描きます。承認待ちのトランザクションはそれぞれ1つの四角形です。積み上がり、マイニングされ、置き換えられていく様子を、数字を読む代わりに目で見られます。

そのまわりに画面がもう4つあります。壁掛けタブレット向けのブロック高の時計、自分の Bitaxe とネットワークのマイニング数値、ブロックエクスプローラ、そしてローソク足と累積出来高デルタと清算を表示する市場タブです。

5つの画面

フィード

生きたモザイクとして見るメンプールと、その横に直近のブロック。色は経過時間、手数料、トランザクション種別から選べます。

時計

ブロック高、手数料、価格、ハッシュレート、半減期までのカウントダウンを、大きな文字で操作ボタンなしに表示します。壁掛けのタブレット向けです。

マイニング

Bitaxe モニターです。自分のマイナーのハッシュレート、ネットワーク難易度に対する最高シェア、温度、電力を表示します。横にはネットワークのハッシュレート、難易度、次の難易度調整が並びます。

エクスプローラ

ブロック高、ハッシュ、txid、アドレスで検索できます。ブロックとその中身をたどり、どのトランザクションが何を置き換えたかも確認できます。

市場

価格をローソク足または折れ線で、出来高、累積出来高デルタ、清算とあわせて表示します。複数の取引所のデータをまとめています。

見たいように設定

タブはどれでもオフにでき、残したタブは好きな順に並べられます。各画面でどの部分を表示するかも自分で決められます。OrangeDeck は見たいものだけを表示します。

  • 使うタブだけ不要なタブをオフにし、順番を入れ替え、起動時の画面を選べます。
  • タブの自動切り替えタブは30秒から10分の間隔で自動的に切り替えられます。どのタブを切り替え対象にするかも選べます。
  • 画面ごとに部分を選ぶヘッダー、フッター、ブロック情報、凡例、チャート、バーは、それぞれ表示と非表示を切り替えられます。時計では、何を大きく表示するかと、値を順番に切り替えるかどうかを選べます。
  • タイルを好みにタイルの配色は経過時間、手数料、種別から、大きさの基準は金額か vBytes から選べます。タイル自体を大きくも小さくもできます。
  • 自分の読み方で市場を見るローソクかライン、出来高か CVD、期間、十字線、取引テープは、どれも設定で選べます。
  • 言語、通貨、データ取得元13の言語と7つの通貨に対応し、自分のノードを含む任意の mempool インスタンスを使えます。

用途

  • Bitaxe モニター自分のマイナーのハッシュレート、最高シェア、温度を、ネットワークの数値と並べて表示します。
  • 壁掛けディスプレイブロック高、手数料、価格を大きな数字で。古いタブレットにどうぞ。
  • DankMaterialShellDMS 用のバーのピル、コントロールセンターのタイル、デスクトップウィジェット。

入手する

Linux デスクトップ全般

普通のウィンドウとして動きます。Wayland に対応し、X11 にも切り替えられます。

ウィジェットやバーとして niri、sway、Hyprland、river、labwc で layer-shell を使います。

Flatpak

バージョン 0.2.15。Flatpak バンドルです：flatpak install --user orangedeck-0.2.15.flatpak。ランタイムは Flathub から入ります。

DankMaterialShell の中で

DMS のプラグイン一覧に載っています。ダッシュボードのタブ、バーのピル、コントロールセンターのタイル、デスクトップウィジェットとして使えます。

GitHub

DMS のプラグイン一覧から入れられます：dms plugins install orangedeck。単体で動き、アプリが起動していればアプリのデータを使います。

Windows

ZIP を展開して起動するだけです。画面は Linux と同じです。

ZIP

バージョン 0.2.15。Windows 10 と 11（64ビット）用の ZIP です。展開して orangedeck-app.exe を起動してください。署名していないため、初回起動時に SmartScreen の確認が出ます。

Android

スマートフォンでもタブレットでも使えます。画面ごとにホーム画面のショートカットがあります。

APKF-DroidObtainium

バージョン 0.2.15。Android 9 以降、64ビット ARM 用です。署名済みで、フィンガープリントはリリースノートに記載しています。

OrangeDeck 独自のリポジトリです。F-Droid、Droid-ify、Neo Store に一度追加すれば、更新は自動で届きます。

macOS

ビルドはできますが、まだ試していません。今のところパッケージはありません。

OrangeDeck の特徴

  1. 01

    表示するだけのアプリです

    秘密鍵を知らず、署名もできず、署名できるライブラリも含んでいません。表示するだけです。

  2. 02

    自前のサーバーはありません

    通信先は mempool.space か、自分のノードを含む選んだインスタンスです。利用状況の集計も、クラッシュレポートも、アカウントもありません。

  3. 03

    推測ではなく計測

    清算ヒートマップのように、数値が計測ではなくモデルに基づく場合は、画面上でそう明示し、前提も書き出しています。

  4. 04

    1つのコードで5つの環境

    ウィンドウ、ウィジェット、パネル、スマートフォンを同じ QML で描いています。1か所で直した不具合は、すべての環境で直ります。

  5. 05

    中身を読めます

    MIT ライセンスで、難読化はしていません。変更の理由はコミットメッセージに残してあります。

よくある質問

鍵は必要ですか？

いいえ。このアプリは鍵を持たず、何にも署名できず、アドレスの入力も求めません。

使わないタブは隠せますか？

はい。どのタブも設定でオフにでき、残りのタブは並べ替えられます。各画面の中の部分も同じで、個々のチャートやバーまで選べます。

データはどこから来ますか？

標準では mempool.space から取得します。設定で別の公開 mempool インスタンスや自分のノードを指定でき、その場合はウィジェットやサービスを含むすべてに適用されます。市場データは取引所の公開フィードから取得します。

どこかにデータを送信しますか？

いいえ。自前のサーバーはなく、アクセス解析もクラッシュレポートもありません。

料金はかかりますか？

かかりません。MIT ライセンスで、有料プランもありません。

対応している言語は？

13言語です。英語、ドイツ語、スペイン語、フランス語、イタリア語、ポルトガル語（ポルトガルとブラジル）、オランダ語、ロシア語、日本語、中国語、ポーランド語、チェコ語に対応しています。起動時はシステムの言語で表示され、数値と日付の書式は設定で選んだ言語に従います。

清算ヒートマップは実データですか？

いいえ。画面上でもそう表示しています。他人のポジションを公開している人はいないため、前提を明記したモデルです。

壁掛けのタブレットで使えますか？

そのための画面が時計です。大きな数字だけで、操作ボタンはありません。Android 版には時計を直接開くショートカットがあります。
