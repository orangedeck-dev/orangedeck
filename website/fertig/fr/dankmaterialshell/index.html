OrangeDeck dans DankMaterialShell

OrangeDeck figure dans l’annuaire des plugins de DankMaterialShell sous le nom OrangeDeck Bitcoin Dashboard. Il s’installe avec une seule commande : dms plugins install orangedeck.

Dans la barre, il se présente comme une pastille avec le nombre de transactions en attente. Un clic ouvre un popout avec les mêmes vues que l’application : Flux, Horloge, Minage, Explorateur et Marché. Il y a aussi une tuile pour le centre de contrôle et un widget de bureau.

Le plugin fonctionne sans l’application et va chercher ses données lui-même sur mempool.space. Si l’application OrangeDeck est installée et que son service tourne, le plugin l’utilise à la place, et toutes les fenêtres partagent ainsi une seule connexion.

Il suit la langue de DankMaterialShell et parle les mêmes treize langues que l’application.

Questions

Quelle version de DMS faut-il ?

DankMaterialShell 1.5.0 ou plus récent, sur n’importe quel compositeur pris en charge par DMS.

Faut-il aussi l’application OrangeDeck ?

Non. Le plugin va tout chercher lui-même. Quand l’application et son service tournent, il partage leur connexion.

Où est le code source ?

Dans son propre dépôt, github.com/orangedeck-dev/dms-plugin, généré à partir du projet principal. Sous licence MIT.
