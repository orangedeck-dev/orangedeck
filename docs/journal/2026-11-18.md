## Android-Bau

- `cmake --build build-android-x86_64` scheiterte: "no member named
  'AOTLookupValidation' in namespace 'QQmlPrivate'". System-Qt seit
  12.10. auf 6.12 (pacman.log), Android-Qt 6.11.2, Host-Pfad /usr.
- `aqt install-qt linux desktop 6.11.2 linux_gcc_64 -O ~/Qt` (15 s),
  `apk.sh` mit `QT_HOST` (`42f7d42`).
- Danach APK 28 MiB: zusaetzlich QtQuick.Controls mit allen Stilen,
  Layouts, Shapes, folderlistmodel. `qml-root-path` enthielt den
  Quellordner; Qt haengt ihn immer an (`Qt6AndroidQmlMacros.cmake`,
  "Primitive QML root path"), `QT_QML_ROOT_PATH` hilft nicht.
  `build-flatpak/var/run -> /run` (von `flatpak build-init`), darunter
  1132 QML-Dateien der laufenden DMS-Shell. Loesung: Worktree auch fuer
  den Arbeitsstand (`3b78a75`); danach 23 MiB, Dateiliste wie 0.2.17.
