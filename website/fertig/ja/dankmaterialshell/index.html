DankMaterialShell の中の OrangeDeck

OrangeDeck は DankMaterialShell のプラグイン一覧に OrangeDeck Bitcoin Dashboard として載っています。インストールはコマンド1つです：dms plugins install orangedeck。

バーには承認待ちトランザクションの件数を示すピルとして収まります。クリックするとポップアウトが開き、アプリと同じフィード、時計、マイニング、エクスプローラ、市場の画面が表示されます。コントロールセンターのタイルとデスクトップウィジェットもあります。

プラグインはアプリがなくても動き、データを自分で mempool.space から取得します。OrangeDeck アプリが入っていてそのサービスが動いていればそちらを使うので、すべてのウィンドウが1本の接続を共有します。

DankMaterialShell の言語設定に従い、アプリと同じ13言語に対応しています。

よくある質問

必要な DMS のバージョンは？

DankMaterialShell 1.5.0 以降です。DMS が対応しているコンポジターならどれでも動きます。

OrangeDeck アプリも必要ですか？

いいえ。プラグインはすべて自分で取得します。アプリとそのサービスが動いていれば、その接続を共有します。

ソースコードはどこにありますか？

専用のリポジトリ github.com/orangedeck-dev/dms-plugin にあり、本体のプロジェクトから生成しています。MIT ライセンスです。
