DankMaterialShell 中的 OrangeDeck

OrangeDeck 以 OrangeDeck Bitcoin Dashboard 的名称收录在 DankMaterialShell 的插件目录中。一条命令即可安装：dms plugins install orangedeck。

它在状态栏里是一个胶囊，显示等待确认的交易数量。点击后打开一个弹出窗口，里面是与应用相同的视图：动态、时钟、挖矿、浏览器和市场。另外还有控制中心磁贴和桌面小部件。

插件不依赖应用，会自己从 mempool.space 获取数据。如果安装了 OrangeDeck 应用并且其服务在运行，插件就改用服务的数据，这样所有窗口共用一个连接。

它跟随 DankMaterialShell 的语言，支持与应用相同的十三种语言。

常见问题

需要哪个版本的 DMS？

DankMaterialShell 1.5.0 或更高版本，任何 DMS 支持的合成器均可。

还需要安装 OrangeDeck 应用吗？

不需要。插件会自己获取所有数据。如果应用及其服务在运行，插件会共用它们的连接。

源代码在哪里？

在单独的仓库 github.com/orangedeck-dev/dms-plugin 中，由主项目生成。MIT 许可证。
