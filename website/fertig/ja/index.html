概要

OrangeDeck はビットコインのメンプールを可視化するアプリです。メンプールを実際の動きどおりに描きます。承認待ちのトランザクションはそれぞれ1つの四角形です。積み上がり、マイニングされ、置き換えられていく様子を、数字を読む代わりに目で見られます。

そのまわりに画面がもう5つあります。壁掛けタブレット向けのブロック高の時計、自分の Bitaxe とネットワークのマイニング数値、ブロックエクスプローラ、ローソク足と累積出来高デルタと清算を表示する市場タブ、そして閲覧専用のアドレスです。

6つの画面

  • 01フィード生きたモザイクとして見るメンプールと、その横に直近のブロック。色は経過時間、手数料、トランザクション種別から選べます。
  • 02時計ブロック高、手数料、価格、ハッシュレート、半減期までのカウントダウンを、大きな文字で操作ボタンなしに表示します。壁掛けのタブレット向けです。
  • 03マイニングBitaxe モニターです。自分のマイナーのハッシュレート、ネットワーク難易度に対する最高シェア、温度、電力を表示します。横にはネットワークのハッシュレート、難易度、次の難易度調整が並びます。
  • 04エクスプローラブロック高、ハッシュ、txid、アドレスで検索できます。ブロックとその中身をたどり、どのトランザクションが何を置き換えたかも確認できます。
  • 05市場価格をローソク足または折れ線で、出来高、累積出来高デルタ、清算とあわせて表示します。複数の取引所のデータをまとめています。
  • 06ウォレット自分のアドレスや xpub を閲覧専用で表示します。自分のトランザクションは山の中にある間、強調表示されます。Linux パソコン上の OrangeDeck サービスが必要で、スマートフォンと Windows からはホームネットワーク経由で利用します。

スクリーンショット

用途

  • Bitaxe モニター自分のマイナーのハッシュレート、最高シェア、温度を、ネットワークの数値と並べて表示します。
  • 壁掛けディスプレイブロック高、手数料、価格を大きな数字で。古いタブレットにどうぞ。
  • DankMaterialShellDMS 用のバーのピル、コントロールセンターのタイル、デスクトップウィジェット。

動作環境

  • Linux デスクトップ全般普通のウィンドウとして動きます。Wayland に対応し、X11 にも切り替えられます。
  • ウィジェットやバーとしてniri、sway、Hyprland、river、labwc で layer-shell を使います。
  • DankMaterialShell の中でDMS のプラグイン一覧に載っています。ダッシュボードのタブ、バーのピル、コントロールセンターのタイル、デスクトップウィジェットとして使えます。
  • WindowsZIP を展開して起動するだけです。画面は同じで、ウォレットは同じネットワーク内の Linux パソコンで動くサービスから取得します。
  • macOSビルドはできますが、まだ試していません。今のところパッケージはありません。
  • Androidスマートフォンでもタブレットでも使えます。画面ごとにホーム画面のショートカットがあります。

数値の出どころ

  • ブロック、メンプール、手数料、ハッシュレートmempool.space の公開 WebSocket、または自分の mempool インスタンスです。切り替えは設定1つです。
  • 価格と約定Binance、Bybit、OKX の公開ストリームです。
  • 清算Bybit と OKX です。ヒートマップは Binance の建玉から作ったモデルで、画面上でもそう表示しています。
  • 自分のマイナーデバイスのローカル API（AxeOS または cgminer）です。問い合わせはホームネットワークの外に出ません。
  • 監視中のアドレス同じ mempool インスタンスへの残高の問い合わせです。鍵は使わず、それ以外に端末から出るものはありません。

OrangeDeck の特徴

  • 01表示するだけのアプリです秘密鍵を知らず、署名もできず、署名できるライブラリも含んでいません。閲覧専用は文字どおり閲覧専用です。
  • 02自前のサーバーはありません通信先は mempool.space か、自分のノードです。利用状況の集計も、クラッシュレポートも、アカウントもありません。
  • 03推測ではなく計測清算ヒートマップのように、数値が計測ではなくモデルに基づく場合は、画面上でそう明示し、前提も書き出しています。
  • 041つのコードで5つの環境ウィンドウ、ウィジェット、パネル、スマートフォンを同じ QML で描いています。1か所で直した不具合は、すべての環境で直ります。
  • 05中身を読めますMIT ライセンスで、難読化はしていません。変更の理由はコミットメッセージに残してあります。

よくある質問

鍵は必要ですか？

いいえ。このアプリは何にも署名できません。監視するアドレスはアドレスか xpub で入力し、残高の問い合わせ以外で端末の外に出ることはありません。

データはどこから来ますか？

標準では mempool.space から、または自分の mempool インスタンスから取得します。切り替えは設定1つです。市場データは取引所の公開フィードから取得します。

どこかにデータを送信しますか？

いいえ。自前のサーバーはなく、アクセス解析もクラッシュレポートもありません。

料金はかかりますか？

かかりません。MIT ライセンスで、有料プランもありません。

対応している言語は？

13言語です。英語、ドイツ語、スペイン語、フランス語、イタリア語、ポルトガル語（ポルトガルとブラジル）、オランダ語、ロシア語、日本語、中国語、ポーランド語、チェコ語に対応しています。起動時はシステムの言語で表示され、数値と日付の書式は設定で選んだ言語に従います。

清算ヒートマップは実データですか？

いいえ。画面上でもそう表示しています。他人のポジションを公開している人はいないため、前提を明記したモデルです。

壁掛けのタブレットで使えますか？

そのための画面が時計です。大きな数字だけで、操作ボタンはありません。Android 版には時計を直接開くショートカットがあります。
