内存池旁边的 Bitaxe 监控

OrangeDeck 的挖矿视图通过本地 API 读取你的矿机，显示算力、最佳份额、温度、功率和风扇转速。它能识别 Bitaxe、NerdAxe 等 AxeOS 设备，以及所有支持 cgminer API 的设备，例如 Antminer、Avalon 或 Whatsminer。

唯一需要设置的是地址，多台矿机填在同一个输入框里，用竖线分隔。请求只发往你家庭网络中的设备，不会发往别处。没有云账户，也不需要登录矿池。

最佳份额会与当前全网难度对比，视图还会按你的算力计算出块概率，分别给出每天的概率和平均间隔。对单台 Bitaxe 来说，这个间隔非常长，OrangeDeck 会如实显示这个数字。

设备旁边是全网数据：从 30 天前一直到 2009 年的算力和难度、下次难度调整、平均出块时间，以及上一个区块的矿池。

这个视图也能作为小部件运行：在 Linux 上是桌面上的 layer-shell 图层，在 Windows 上是无边框窗口，在 Android 上是主屏幕小部件。

常见问题

OrangeDeck 支持哪些矿机？

Bitaxe、NerdAxe 等 AxeOS 设备，以及支持 cgminer API 的矿机，例如 Antminer、Avalon 和 Whatsminer。

矿机数据会离开我的网络吗？

不会。OrangeDeck 直接访问设备的本地地址，不经过任何服务器。

可以同时监控多台矿机吗？

可以。在设置中输入地址，用竖线分隔，例如 http://192.168.1.42|http://192.168.1.43。
